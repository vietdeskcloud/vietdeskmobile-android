# VIETDESKMOBILE cho Android

Tải bản cập nhật chính thức tại [GitHub Releases](https://github.com/vietdeskcloud/vietdeskmobile-android/releases).

1. Mở bản phát hành mới nhất và tải `VIETDESKMOBILE.apk` trong mục **Assets**.
2. Mở tệp APK trên điện thoại Android và làm theo hướng dẫn cài đặt. Nếu Android yêu cầu, hãy cho phép cài ứng dụng từ trình duyệt hoặc ứng dụng quản lý tệp đang mở APK.

Nếu đã cài VIETDESKMOBILE, hãy cài bản cập nhật trực tiếp lên ứng dụng đang có. Nếu Android từ chối cập nhật, hãy liên hệ VIETDESK trước khi gỡ ứng dụng để tránh mất dữ liệu lưu trên máy.
